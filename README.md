# Pippa's Keep

A Year 10 English study app covering Wilfred Owen's war poems, The Great Gatsby and Macbeth. Lessons, quizzes and typed quote recall earn coins, and the coins build a castle.

It has 37 lessons, two stories in pictures (The Great Gatsby and Macbeth), 83 quotes to learn by heart, a test for each of the three texts and a castle of 31 items to build.

It is a static site with no build step. Open `index.html`, or serve the folder with GitHub Pages from the `main` branch root.

Progress is saved in the browser on the device being used.
